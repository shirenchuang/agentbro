A. Inline Status

Spinner + one-line status text directly in the row. Shows the command being run (e.g. "npm install -g ..."). Row gets a subtle blue border while working. Simple, no extra panels.

B. Expandable Terminal

Row has a collapsible terminal output area. Shows real-time command output, useful for debugging install failures. Output area auto-scrolls. Error state shows red border + Retry button.

Both options include:

  • Error handling — failed installs show error message + Retry button
  • InlineConfirm for Uninstall — same two-state button pattern from Skills
  • Concurrent installs — can install/update multiple agents at once
