B. List View

Compact rows with inline action buttons. Shows package manager, version, and status at a glance. Filter tabs at top (All / Installed / Available). More info-dense.

Key features for both options:

  • One-click Install — runs the correct package manager command (npm/pip/brew/go)
  • One-click Update — detects available updates, updates to latest
  • One-click Uninstall — with inline confirm (same pattern as skill uninstall)
  • Auto-detect — scans system for installed agents on page load
  • Version display — shows current version, highlights when update available
  • 22 agents — Claude Code, Codex, Gemini, Cursor, Copilot, Trae, Qoder, CodeBuddy, Qwen, Kimi, OpenCode, Droid, StepFun, AntiGravity, WorkBuddy, Hermes, Pi, Kiro, etc.
