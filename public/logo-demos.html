Bro Badge redesign

让 B 像一个可靠的 AI 搭子。

这次只聚焦 Bro Badge：保留 `B` 作为识别锚点，把 “bro” 表达成两个 agent 节点并肩、接力、互相兜底。

Prime：Bro Badge 主案

`B` 不能只是字母，要像一个产品符号。左侧竖线是稳定的 “bro backbone”，上下两个环是两个 agent 节点，右上角小光点像随时在线的伙伴。

识别 先读成 B，再读成两个 agent 并肩。
气质 不搞怪，像靠谱搭子，有一点酷。
尺寸 32px 仍保留 B 轮廓和双节点。
延展 可做 favicon、Dock、启动页和官网标。

小尺寸测试

如果一个 logo 在 28px 还看得出主轮廓，它才配当 app logo。这版刻意减少细节，把 bro 感集中在双节点结构里。

我会继续打磨哪里

下一步不是再换概念，而是微调：`B` 的弯曲比例、上下环间距、外框圆角、亮色面积。目标是让它更像 macOS 图标，而不是前端 SVG 插画。
