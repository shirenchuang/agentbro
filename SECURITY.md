# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities, leaked secrets, signing problems, or anything that could put users at risk.

Use GitHub's private vulnerability reporting flow if it is available for this repository. If that is not available, contact the maintainer through the community channels listed in the README and include:

- The affected AgentBro version or commit.
- A clear description of the issue and impact.
- Reproduction steps or a minimal proof of concept.
- Any relevant logs with tokens, hostnames, private paths, and secrets removed.

We will acknowledge valid reports as quickly as possible and coordinate a fix before publishing details.

## Supported Versions

Security fixes target the latest public release and the current `dev` branch unless maintainers state otherwise in a release note.
